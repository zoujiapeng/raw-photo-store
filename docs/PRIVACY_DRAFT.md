# 隐私说明草案

本文件用于开发阶段，不应未经法律与地区审核直接作为正式隐私政策发布。

RAWJudge 可能处理账号标识、头像、作品、RAW、EXIF、设备与安全信号、评论、评分、举报、申诉、授权和审计记录。RAW 可能包含拍摄时间、设备型号、地理位置或其他元数据；上传前应明确提示用户并允许移除非必要定位信息。

数据仅用于作品展示、真实性验证、内容安全、质量评审、反作弊、授权履行和平台安全。原始 RAW 不应作为公开 CDN 资源；仅通过短期签名地址向作者或已授权购买者提供。生产环境必须设置保留期限、删除流程、导出流程、访问控制、加密、审计和事件响应机制。

禁止把用户 RAW 或作品用于模型训练，除非获得单独、明确、可撤回的授权。第三方 AI 服务只接收完成任务所需的最少信息，并应在正式政策中列明服务商、地区和保留规则。
