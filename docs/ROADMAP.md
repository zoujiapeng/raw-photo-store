# 路线图

## 0.1（本仓库）

- Android 完整交互原型。
- FastAPI 核心 API 与测试。
- RAW 文件硬规则、评论分析、盲评、审计和授权。
- GitHub CI 与 APK artifact。

## 0.2

- Android API Repository、Room 缓存和 WorkManager 大文件上传。
- 登录、用户资料、关注与外部平台入口编辑。
- 对象存储、签名 URL、缩略图流水线和 EXIF 解析。
- 管理员审核台。

## 0.3

- RAW 派生预览和成片一致性模型。
- 成对比较排名模型、评审信誉校准、团伙互评检测。
- 通知、搜索、主题评审和作品收藏夹。

## 1.0

- 支付与创作者结算。
- 不可变授权合同快照和下载审计。
- 地区化内容规则、隐私与数据保留策略。
- 生产监控、灾备、灰度、风控评测和应用商店发布材料。
